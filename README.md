# Brunelli Games — site (GitHub Pages)

Página inicial dos jogos, políticas de privacidade (pt/en) e `app-ads.txt` do AdMob.

- Publicado em `https://pliniobrunelli.github.io` (repositório `pliniobrunelli.github.io`, branch `main`).
- As páginas são geradas por `build.py`: edite o `CONFIG` (e-mail, ID de publisher `pub-…`, datas) ou os textos e rode `python build.py .`.
- `app-ads.txt` precisa ficar na raiz do domínio informado como "site do desenvolvedor" na Google Play.
